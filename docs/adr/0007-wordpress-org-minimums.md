# Built for the wordpress.org directory, with WordPress 6.6, WooCommerce 9.0 and PHP 7.4 minimums

The free plugin is published on wordpress.org, so it is GPLv2-or-later, must pass the Plugin Check plugin with no errors, declares compatibility with High-Performance Order Storage and the Block checkout, and is translation-ready under the `checkout-fieldkit` text domain. It requires WordPress 6.6+, WooCommerce 9.0+ and PHP 7.4+.

The reference plugin supports WordPress 5.0 and PHP 5.6. Matching that would rule out the React admin on WordPress's bundled packages and modern PHP for very few real stores, so we chose not to. PHP 7.4 rather than 8.x keeps the directory's reach while hosting catches up; raising it later is easy, lowering it is not.
